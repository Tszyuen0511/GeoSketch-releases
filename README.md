# GeoSketch

Windows application downloads and update notes only. Application source is held in a separate private repository.

[Download the latest release](https://github.com/Tszyuen0511/GeoSketch-releases/releases/latest)

Download **GeoSketch-Windows-vX.Y.Z.zip** from release assets, extract the entire folder and run **Launch GeoSketch.cmd**. No separate Python installation is needed. The automatic GitHub source archives are not the application download.

Keep your projects and output outside the application folder. To update, close GeoSketch and extract the new complete package into a new folder.

Use **About > Check for updates** for a manual version check.

[User tutorial](https://tszyuen0511.github.io/soil-model-tutorial/)

Surface generation needs licensed Surfer 12.7.984; DWG boundary import needs AutoCAD Core Console; PLAXIS geometry scripts target PLAXIS 2D 2024.2.
